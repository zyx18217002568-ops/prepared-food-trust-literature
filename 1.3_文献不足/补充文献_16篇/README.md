# 1.3节三个文献缺口：16篇补充文献

本目录汇集围绕论文第1.3节三个研究缺口筛选并下载的16篇高相关中英文论文。

## 主题范围

1. 食品安全信息透明、追溯和标签的支持偏好与实际增信效果之间的差异；
2. 不同信息呈现或信息干预的实验、准实验与情境比较；
3. 既有食品安全态度、制度或政府监管信任对信息效果和食品安全判断的作用。

## 文件说明

- `PDF全文/`：16篇公开获取的论文PDF；
- `详细概要/16篇论文详细概要_Luna.md`：适合直接在GitHub浏览的逐篇阅读笔记；

每篇概要均包括完整题录、摘要概括、研究背景与问题、正文概要、研究方法及过程、主要结果、结论、局限与适用边界，以及对三个文献缺口的具体价值。
