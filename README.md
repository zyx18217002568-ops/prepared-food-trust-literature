## 1.3 节补充文献

`1.3_文献不足/补充文献_16篇/` 收录围绕以下三个文献缺口筛选的16篇高相关中英文论文：

1. 消费者对食品安全信息透明、追溯和标签的支持偏好，与实际增信效果之间的差异；
2. 不同信息呈现方式或信息干预的实验、准实验及情境比较；
3. 既有食品安全态度、制度信任及政府监管信任对信息效果和安全判断的作用。

该目录包括：

- `PDF全文/`：16篇公开获取的论文全文；
